# Image Detector Evaluation

This directory contains the evaluation script for the VeriMedia AI image detector.

## Dataset Structure

The evaluator expects the following directory structure:

```text
evaluation/
├── dataset/
│   ├── real/
│   │   ├── image1.jpg
│   │   ├── image2.jpg
│   │   └── ...
│   │
│   └── ai_generated/
│       ├── image1.png
│       ├── image2.png
│       └── ...
